# Mapa Marvel

App para acompanhamento da linha do tempo da Marvel — filmes e séries da Marvel Studios (MCU), Sony, 20th Century Fox, Marvel Television e Marvel Animation, de 2000 até hoje, com uma aba separada para produções anteriores a 2000.

## Visualizações (2000 até hoje)

- **Por Estúdio & Fase** — agrupado por estúdio e, no caso da MCU, por fase, na ordem de lançamento.
- **Cronologia da História** — todos os estúdios misturados numa única linha do tempo, ordenados pela época em que cada trama se passa (não pelo lançamento), conectando universos que nunca se cruzaram oficialmente.
- **Cronologia de Lançamento** — todos os estúdios misturados na ordem real de estreia, sem separação por franquia.

A aba **Antes de 2000** reúne seriados, filmes para TV e longas anteriores à era moderna do cinema de super-heróis.

## Rodando localmente

```bash
npm install
npm run dev
```

Otimizado para uso em iPhone: responsivo, com suporte a "Adicionar à Tela de Início" (PWA) e áreas seguras de notch/home indicator.

## Build

```bash
npm run build
```
